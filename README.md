# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from data collection to business insights. It includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, interactive dashboard creation in Power BI, and final reporting.

The objective is to transform raw data into meaningful insights that support better decision-making.

---

## Dataset

* Dataset: *Customer Shopping Behavior*
* Source: *UCI Repository*
* Format: CSV
* Description: The dataset contains information used to perform data analysis, identify trends, and generate actionable insights.

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python.
* Inspected data structure and data types.

### 2. Exploratory Data Analysis (EDA)

* Analyzed dataset characteristics.
* Generated summary statistics.
* Visualized trends, distributions, and relationships.
* Identified missing values and outliers.

### 3. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected inconsistent data.
* Converted data types where required.

### 4. SQL Analysis

* Imported cleaned data into PostgreSQL/MySQL/SQL Server.
* Executed SQL queries using:

  * SELECT
  * WHERE
  * GROUP BY
  * ORDER BY
  * JOIN
  * Aggregate Functions
  * Subqueries (where applicable)

### 5. Power BI Dashboard

Created an interactive dashboard featuring:

* KPI cards
* Charts and graphs
* Filters and slicers
* Trend analysis
* Business insights

### 6. Report & Presentation

* Prepared a detailed analytical report.
* Created a presentation using Gamma to summarize findings and recommendations.

## How to Run

1. Clone the repository.
2. Install the required Python libraries:

   ```bash
   pip install -r requirements.txt
   ```
3. Open the Jupyter Notebook or Python script.
4. Run the data loading and EDA steps.
5. Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
6. Execute the SQL scripts.
7. Open the Power BI file to explore the dashboard.
8. Review the report and presentation for the final insights.
